## Что это
Домашний экран для Google TV / Android TV вместо штатного + приложение настроек; те же функции на LG webOS и Samsung Tizen как веб-приложение (`web/`, `webos/`, `tizen/`). Русская редакция: Яндекс-погода, мультяшное небо, VPN-страж и выбор сервера V2RayTun, ночные часы, таймер сна, generic-сборка для любого Android TV. Java без Gradle, сборка `build.sh`.

## Где что
- GitHub: public `megaday2020-alt/free-my-tv-ru`. Локально git-remote называется **`mine`** (не `origin`), ветка `main`. Remote `origin` у владельца указывает на чужой upstream `simbasjungles/free-my-tv`: пушить только в `mine`.
- Сайт проекта: `docs/` (статика EN + `docs/pt/` PT-BR; менять обе версии), публикуется GitHub Pages workflow'ом `.github/workflows/pages.yml` при пуше в `main`.

## Сделано 2026-11-01 (дача, Xiaomi Mi TV MOOQ1, Android 11): НЕ закоммичено, не запушено
- `./build.sh --dacha` собирает `FreeMyTV-dacha.apk` из `config.dacha.properties` (в `.gitignore`; город дачи). 
- Погода: проверка тумана через Open-Meteo (Яндекс и MET в тумане пишут «ясно»); туман пишется в кэш `yaCode`, иначе после перезапуска возвращалось «ясно».
- Нижнее меню: входы HDMI только с сигналом; кнопка «Закрыть все» (force-stop сторонних приложений, кроме Free My TV, V2RayTun, Shadowsocks).
- VPN: рядом со значком время отклика (медиана трёх; оранжевое >400 мс, красное >800: для видео хватает); замер в фоне (`VpnPing`, :home процесс) раз в 30 с (10 с при сбое), цифра готова сразу при возврате на главный экран. Работает, только если Free My TV добавлен в список приложений V2RayTun (режим «выбранные приложения»), иначе замер идёт мимо VPN.
- Местоположение: сборка со своим городом при первом запуске сохраняет его в настройки TV (`Prefs.pinLocation`), поэтому обновление универсальной сборкой из GitHub город не сбрасывает.
- Заставка (новости и погода переделаны 2026-11-01, см. ниже; одна на всё: система по бездействию, плитка «Заставка», таймер сна; `InfoView`, хост `Screensaver`/`DarkActivity`; прежняя фото-заставка `DreamView` в коде осталась, но не используется): тёмная панель с медленным свечением по погоде; карточки с выключателями: часы и дата, погода (сейчас, 6 часов, 5 дней, восход/закат, осадки скоро), новости (`NewsFeed`: RSS Лента.ру / РИА / Интерфакс, 4 заголовка, смена раз в 30 с, обновление раз в 10 мин, прямое соединение мимо VPN), курсы ЦБ (`Rates`: cbr.ru XML, запасной JSON), связь (VPN-задержка с цветом, Wi-Fi). Яркость: Авто (ночью темнее)/Тусклая/Средняя/Яркая; «Экономия экрана»: через N мин (по умолчанию 10) остаются тусклые часы на чёрном, анимации стоят, яркость панели 0.02 (запрос системе принят, `dumpsys display`; сработает ли подсветка, зависит от телевизора). Настройки: Главный экран → Заставка. Плитки «Соединение» (было «Проверить сеть») и «Заставка» помещаются. Экономия по таймеру вживую не проверена.
- Xiaomi: коды кнопок сняты (иви 199, okko 200, VK 188, rutube 203, kion 198, wink 197); привязаны в `RemoteKeys.XIAOMI_KEYS`, `DISCOVER=false`. Проверено по журналу: иви, rutube, wink, okko открывают нужные приложения.
- Выбор сервера: обновить подписки, выключить VPN (виджет V2RayTun), замерить, выбрать, включить; страж на это время молчит (`VpnServers.vpnHeldOff`); после выбора проверка доступа, при провале перебор 3 лучших серверов (подсветка выбранной строки в V2RayTun не читается, «текущий» может быть неверным). Не переключать по старым цифрам, если кнопка теста не найдена; не перебирать серверы, если нет интернета вообще. Интервал 6 ч; в 4:00 открытое приложение сворачивается (пауза), потом открывается снова.
- Xiaomi: кнопки пульта (иви, okko, kion, VK, rutube, wink) приходят как `KEYCODE_BUTTON_1..16`, их ловит служба `RemoteKeyService`. Сейчас режим `RemoteKeys.DISCOVER=true` (глотает и пишет в журнал «xiaomi remote key N»); коды ещё не сняты.

## Заставка: новости из Telegram и компактная погода (2026-11-01, дача)
- `NewsFeed`: источники Топор и Ateo Breaking (https://t.me/s/NAME, разбор HTML: просмотры, время, реклама/подписи/ссылки/хештеги вычищены), РИА, Лента.ру, Интерфакс (RSS). Важность поста = просмотры / медиана 6 ближайших по времени постов канала (просмотры растут с возрастом поста, поэтому сравнение с соседями, а не с общей медианой), +0.25 за блок реакций. Порог: Больше 1.15, Обычно 1.3, Главное 1.7; если важных меньше 3, показываются лучшие по рейтингу. РИА (RSS) без рейтинга: показывается, если подтверждён важным постом, либо если Telegram-каналы выключены. Дубли (общие слова) склеиваются, теги объединяются («Топор · РИА»). Кэш SharedPreferences "news" ключи d<N>/bt<N>. Загрузка `HomeData.open`: на ТВ работает (Топор 12, Ateo 20 постов, в журнале строки `news:`).
- Настройки: новая группа «Новости заставки» (Новости, Только важное, переключатели 5 источников); в «Заставке» осталось 7 строк. Prefs: `newsMask` (по умолчанию Топор+Ateo+РИА), `newsImportant` (по умолчанию «Обычно»).
- `InfoView`: 7 заголовков на страницу с тегом источника, погода компактная (сейчас, сегодня, 2 дня), карточка связи под погодой, новости на всю высоту правой колонки.
- Важность = просмотры относительно соседних постов + слова заголовка (`NewsFeed.boost`: серьёзные темы плюс, шоу/спорт/скидки минус); без «квоты» на канал (она тянула неважное), если пусто, берутся 3 лучших. Топор сейчас почти не проходит отбор (его просмотры плоские).
- Баланс источников (устарело, см. выше): у каждого Telegram-канала всегда показываются лучшие 2-4 поста (по уровню), не больше 6 от одного канала; карточка «Связь» по размеру текста. Установлено на ТВ 13:5x, но скриншотом не проверено (ТВ пропал из сети).
- Дача: на ТВ (не в коде) выставлено `settings put secure sleep_timeout 1800000`: заставка с 5-й минуты (screen_off_timeout 300000), сон через 30 мин без действий. Живую проверку 30 мин не делали. Слабый Wi-Fi на ТВ: adb обрывается после установки.
- Новости теперь лента без отбора по умолчанию (`newsImportant`=0): Топор, Ateo, РИА по времени, сообщения целиком, до 3 строк, длиннее 135 знаков не показываются (`NewsFeed.MAX_CHARS`). Яркость заставки: `Backlight.java` меняет `settings global picture_backlight` (подсветка Xiaomi, окно Android её не трогает) через ADB ТВ и возвращает при выходе; сохранённое значение на диске, `HomeActivity.onResume` и загрузка возвращают, если заставка умерла. Установлено, живая проверка яркости и экрана новостей ещё не сделана.
- Урок: установка приложения при включённой системной заставке убивает её, и ТВ сразу уходит в сон (причина `timeout`, 14:14). Не ставить сборки, пока заставка идёт.
- Из ленты убираются посты «одна фраза + фото/видео/документ» (`NewsFeed.onePhrase`): смысл в медиа, его не видно. Собрано, на ТВ не установлено (владелец смотрит ТВ; не ставить при работающей заставке).
- Заголовки в карточке сокращаются до ~74 символов (`NewsFeed.fit`: по запятой/тире, иначе по слову), чтобы влезали в 2 строки.
- Решения владельца (идеи): фон «Фото дня» пока не нужен; QR у новости, тема по закату/восходу, дорога до дома (ключ TomTom под вопросом: покрытие в России сомнительно) отложены/ждут подтверждения; курсы валют не нужны (убрать); напоминания отложены на потом; праздники и ночной режим не нужны.
- Не проверено: рейтинг на разных днях (в тихий день могут показываться лишь 3 заголовка), Лента/Интерфакс вживую, английский вариант текстов. Коммит локальный, не запушен.
