# Установка Free My TV на другой телевизор или приставку (Xiaomi, Android TV, Google TV)

Подойдёт любой телевизор или приставка на **Android TV / Google TV с Android 9 или новее**. Это в том числе Xiaomi Mi TV и Mi Box, TCL, Sony, Philips, Hisense, Realme, onn, Chromecast with Google TV, Nvidia Shield и безымянные коробки на Android TV. Телевизоры LG (webOS) и Samsung (Tizen) тоже поддерживаются, но другим способом (см. `README.md`, разделы LG и Samsung).

> **Честно о проверке.** Приложение целиком проверено только на одной приставке (Mediaroom v3.2, Android 10). На Xiaomi и других моделях оно не тестировалось. Главный экран и заставка работают на любом Android TV; всё, что связано с VPN (V2RayTun), включается только если V2RayTun установлен. Если что-то на вашей модели ведёт себя странно, кнопка «Оригинал» возвращает заводской экран (см. ниже).

## Что понадобится
- Компьютер (Windows, macOS или Linux) в той же сети Wi-Fi или по кабелю, что и телевизор.
- Файл `FreeMyTV-generic.apk` (универсальная сборка из GitHub Releases или из архива проекта).
- 10 минут.

## Шаг 1. Включить отладку на телевизоре
1. **Настройки → Параметры устройства (или «Система») → О системе → Версия ОС / Номер сборки**: нажмите на номер сборки **7 раз** (появится «Вы стали разработчиком»).
2. Вернитесь назад: **Для разработчиков** (Developer options) → включите **Отладка по USB** (USB debugging). Если есть пункт **Отладка по сети / ADB через сеть**, включите и его.
3. Узнайте IP-адрес телевизора: **Настройки → Сеть и интернет → ваша сеть** (например, `192.168.1.50`).

> На Xiaomi пункт «Для разработчиков» иногда прячется в **Настройки → Параметры устройства → Дополнительно** или в **Настройки → О системе**. Если порт отладки не открывается, перезагрузите телевизор после включения отладки.

## Шаг 2. Установить приложение
**Windows** (PowerShell, из папки `install`):
```powershell
.\install.ps1 -Ip 192.168.1.50
```
**macOS / Linux**:
```bash
./install.sh 192.168.1.50
```
Скрипт сам скачает `adb` (Windows), подключится к телевизору и установит приложение. На экране телевизора появится вопрос **«Разрешить отладку по USB?»**: отметьте **«Всегда разрешать»** и нажмите «ОК».

Вручную то же самое:
```bash
adb connect 192.168.1.50:5555
adb install -r FreeMyTV-generic.apk
```

## Шаг 3. Включить новый главный экран
На телевизоре откройте **Free My TV** (значок в списке приложений) → **Главный экран** → **Free My TV**. Телевизор ещё раз спросит про отладку (это уже само приложение): снова «Всегда разрешать». Нажмите кнопку «Домой»: должен открыться новый экран.

Приложение само определит язык, а город для погоды возьмёт из часового пояса телевизора. Поменять город и остальное можно в **Free My TV → Главный экран** (язык, температура, тема, город, анимация, звуки, ночное обслуживание).

## Как вернуть всё как было
Откройте **Free My TV → Главный экран** и выберите **Оригинал**: заводской экран, заставка и выключенные приложения вернутся. Приложения никогда не удаляются, только отключаются, и «Оригинал» их включает обратно.

Если телевизор вдруг «завис» на чёрном экране, с компьютера:
```bash
adb connect 192.168.1.50:5555
adb shell pm enable <имя пакета заводского экрана>
adb shell cmd package set-home-activity <заводской экран>
```
Имя заводского экрана смотрите так: `adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.HOME` (до установки; на Xiaomi это, как правило, `com.mitv.tvhome` или `com.google.android.tvlauncher`).

## Что работает не везде
| Возможность | Требует |
|---|---|
| Главный экран, заставка, часы, погода, значки Wi-Fi и температуры | любой Android TV 9+ |
| Погода Яндекса | включается сама в России, Беларуси, Казахстане и соседних странах; в остальных странах работает норвежский MET |
| Кнопки «Очистить кэш», «Перезагрузить», ночное обслуживание | включённая отладка по USB |
| Таймер сна, «Ночные часы» | любой Android TV |
| Страж VPN, выбор сервера, индикатор связи | установленный **V2RayTun** (без него эти пункты скрыты или ничего не делают) |
| Кнопки приложений на пульте | только TCL и Vestel |
| Подборки фильмов TMDB | бесплатный ключ TMDB, который вы вписываете сами (см. `README.md`); из некоторых стран TMDB заблокирован |

## Если ваша модель отличается от проверенной
Читайте раздел «Adapting it to another TV» в `CLAUDE.md`: там список команд, которые безопасно выполнить для разведки, и места в коде (`HomeMode.DEBLOAT`, `HomeMode.PROTECTED`), куда добавляют «лишние» приложения конкретной марки. Что при включении отключается (никогда не удаляется, «Оригинал» всё включает обратно): на любом телевизоре Play Games и YouTube Music; на Xiaomi дополнительно телеметрия (`com.miui.tv.analytics`, `com.xiaomi.statistic`) и промо Mi TV+ (`com.mitv.tvhome.mitvplus`, `com.xm.webcontent`); у TCL, Multilaser и Philco свои списки рекламных и служебных приложений. Заводской экран (на Xiaomi это PatchWall или Google TV Launcher) приложение тоже отключает на время работы (не удаляет) и возвращает кнопкой «Оригинал»; именно поэтому «Оригинал» нужно знать наизусть. На марках, которых приложение не знает, лишнего не трогается.
