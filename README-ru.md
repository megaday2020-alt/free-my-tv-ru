# Free My TV (русская сборка с VPN и погодой)

Быстрый главный экран для Android TV и Google TV без рекламы, с погодой, мультяшной анимацией неба, значками статуса (VPN, Wi-Fi, температура), быстрыми кнопками и таймером сна. Это доработанная версия проекта [Free My TV](https://github.com/simbasjungles/free-my-tv) (лицензия MIT), сделанная для приставки с Android 10 и затем обобщённая для других телевизоров.

Подробный отчёт о том, как всё делалось: [`docs/PROJECT-REPORT-ru.md`](docs/PROJECT-REPORT-ru.md).

## Что умеет
- **Главный экран:** большие часы, погода «сейчас / днём», ветер значком, прогноз на 2 дня и на 6 дней в нижнем меню, градиентный фон и анимация (солнце и луна по дуге, облака, дождь, снег, гроза), шрифт Manrope.
- **Погода:** публичная страница Яндекса (Россия и соседние страны) или MET Norway; город по часовому поясу телевизора, меняется в настройках.
- **Быстрые кнопки** (панель по стрелке вниз): проверка сети (Wi-Fi, роутер, интернет, VPN), очистка кэша, перезагрузка (с подтверждением), «Ночные часы» вместо сна, таймер сна 15–120 минут.
- **Ночное обслуживание:** в 4:00 очистка кэша, раз в неделю перезагрузка (только когда телевизор свободен).
- **VPN (если установлен V2RayTun):** индикатор связи через VPN, страж, который возвращает VPN, автовыбор лучшего сервера по пингу.
- **Обновление приложения:** раз в ночь ищет новую версию на GitHub; ставится только по вашему «Установить» (Настройки → «Обновление приложения»), на значке настроек горит жёлтая точка.
- **Тёплый экран вечером (экспериментально, на разных телевизорах работает не везде):** режим «для глаз» от заката до рассвета, один мягкий уровень; яркость не меняется.
- **Отчёт за неделю:** сколько раз пропадал VPN, сколько раз страж его вернул, температура приставки.
- Ничего не удаляется: «Оригинал» возвращает заводской экран.

## Установка на другой телевизор
Подробно: [`install/INSTALL-ru.md`](install/INSTALL-ru.md).
```
# Windows (PowerShell)         .\install\install.ps1 -Ip 192.168.1.50
# macOS / Linux                ./install/install.sh 192.168.1.50
```
Нужен Android TV или Google TV с Android 9+ (Xiaomi, TCL, Sony, Philips, Hisense, Chromecast with Google TV, Nvidia Shield и т. д.), включённая «Отладка по USB» и APK универсальной сборки `FreeMyTV-generic.apk` (из «Releases» или собранный `./build.sh --generic`).

> Проверено вживую на одной приставке (Android 10). На Xiaomi и других моделях живой проверки не было: если что-то идёт не так, нажмите «Оригинал» в приложении.

## Сборка
Нужны JDK 17 и Android SDK (build-tools 34, platform android-34), на Windows через Git Bash.
```
./build.sh              # FreeMyTV.apk со своими настройками (config.properties)
./build.sh --generic    # FreeMyTV-generic.apk: без личных данных, город по часовому поясу
```
Ключ подписи `freemytv.keystore` создаётся при первой сборке. **Храните его и не публикуйте**: без него нельзя ставить обновления поверх.
